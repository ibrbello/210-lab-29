Function 2: hiringEvent()
This test will ensure that the hiring event did in fact add employees
to the correct list. The test will create a empty container of employees.

Then it will call hiringEvent(). The contents of the workforce container
will then be printed to verify that employees were in fact hired.

Test:
   // Test for hiringEvent() 
   cout << "Testing hiring function..." << endl;
   // initialize empty workforce map
   map<string, array<list<string>, NUM_ROLES>> testWorkforce = {
    {"Finance", {{{},{},{}}}},
    {"Product", {{{},{},{}}}},
    {"Marketing", {{{},{},{}}}},
    {"HR", {{{},{},{}}}}};

   // print out original state
   for (auto it = testWorkforce.begin(); it != testWorkforce.end(); it++)
   {
       displayDepartment(it->first, it->second);
   }
   // Check that the hiring event worked for different departments
   hiringEvent(testWorkforce, "Finance");
   displayDepartment("Finance", testWorkforce["Finance"]);

   hiringEvent(testWorkforce, "HR");
   displayDepartment("Finance", testWorkforce["Finance"]);
   displayDepartment("HR", testWorkforce["HR"]);
  

Function 3: layoffEvent()
This test will be similar to the test for hiringEVent(). There will be
three sets of tests: one with a workforce that is full (more employees than
possible layoffs), another with a workforce that is almost empty (potential to
have more attempted layoffs than employees), and another with an empty workforce.
This test will evaluate the function's performance in all 3 scenarios. 
Print statements are also added within the function to assess the function's logic.
